# サイクル10.8: DevRelay 席の追加（Opus 4.8 / Sonnet 5）

日時: 2026-09-20 21:50 JST

## 変更

- `llm/models.py` に、既定ロスター外・サブスクリプション課金の DevRelay 席を2つ追加した。
  - `DR_OPUS48`: `devrelay/claude-opus-4-8`
  - `DR_SONNET5`: `devrelay/claude-sonnet-5`
- `tools/devrelay_smoke.py` に `--model`（既定 `DR_FABLE`）と、並走確認用の
  `--seat-key`（既定 `P05`）を追加した。DevRelay 席でないキーは呼び出し前に拒否する。
- `tests/test_devrelay_http.py` のレジストリ検証を5席へ拡張し、新2席の属性と
  model_id 逆引きを固定した。

## 検証

- 関連テスト: `uv run pytest tests/test_registry_18.py tests/test_devrelay_http.py` — 49 passed
- 全テスト: `uv run pytest` — 1830 passed（既存の warning 4件のみ）
- 実DevRelay単体スモーク: `DR_OPUS48` は HTTP 400 で拒否された。
  - エラー本文: `aiUnavailable: raw-completion only supports Claude (project defaultAi=codex)`

  `DR_SONNET5` の3席並走は未実行。DevRelay 側の対象プロジェクト許可設定の確認が必要。
