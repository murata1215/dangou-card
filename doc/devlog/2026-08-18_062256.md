4. ユーザー指摘3: 事前確認コマンドに `--dry-run` が抜けていた。→ Run A/B とも「dry-run実行→期待値と一致確認→`--dry-run`を外して実API実行」の4ステップ構成に修正し、dry-run合否判定（対象モデル数・最悪見積・実行順・spent_usd不変）を明記。
