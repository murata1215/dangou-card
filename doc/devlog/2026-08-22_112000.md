# Viewer再起動: P12脱落重複表示修正の本番反映

## 背景

`2026-08-22_104500.md` で `viewer/log_parser.py` の `get_round_states()` に脱落重複排除
（`add_elimination()`）を実装し、テスト（新規8件含む全780件）はグリーンだったが、稼働中の
`dangou-viewer.service`（Main PID 1378197, 2026-08-22 10:29:00起動）はP09修正のみを載せた
時点のコードを実行しており、P12修正は未反映のままだった。本作業でサービスを再起動し、
実trial（`trial_C_l12_r12_20260822/game01`）で実表示を検証した。

## 実施内容

1. 再起動前スナップショット取得（読み取りのみ）
2. `systemctl --user restart dangou-viewer.service` を実行（unit/env/Caddy設定は無変更、
   `daemon-reload` 不要）
3. サービス健全性確認：`active (running)`、PID変化、9023番ポートLISTEN、
   journalにエラー/traceback無し
4. 主要API 7本のHTTP 200確認
5. P12重複解消・P09維持・既存脱落経路無回帰・survivors・god認可を実APIで確認
