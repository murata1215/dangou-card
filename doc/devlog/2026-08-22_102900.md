# Viewer再起動・実表示検証（AUTO_COMMIT_FAILURE脱落表示修正の反映）

## 背景

`2026-08-22_094134.md` で `viewer/log_parser.py` の `AUTO_COMMIT_FAILURE` 取りこぼしバグを修正し、
テスト（新規6件含む全772件）はグリーンだったが、稼働中の `dangou-viewer.service`（PID 1306737,
2026-08-21 17:21起動）は旧コードを実行し続けており、公開UIには未反映だった。
本作業ではサービスを再起動し、実trial（`trial_C_l12_r12_20260822/game01`, R12完走済み）で
実表示を検証した。

## 実施内容

1. **再起動前スナップショット**取得（読み取りのみ）
2. `systemctl --user restart dangou-viewer.service` を実行（unit/env/Caddy設定は無変更、
   `daemon-reload` 不要）
3. サービス健全性確認：`active (running)`、PID変化、9023番ポートLISTEN、journalにエラー/traceback無し
4. 主要API 6本のHTTP 200確認
5. P09脱落表示・既存脱落経路の非破壊・R12閲覧可否を実APIで確認
6. public/god認可境界（token無しで403）を確認。値レベルの一致は既存回帰テスト
   `test_auto_commit_failure_view_parity` で担保
7. `/tmp/origviewer/`（読み取り専用の事前調査用スクラッチ）を削除

## 結果

|---|---|---|
| Main PID | 1306737 | **1378197** |
| 9023 LISTEN | 旧PIDで維持 | 新PIDで維持 |
| survivors | 6 | **5**（Engine真値と一致） |
| eliminated | P01,P02,P06,P07,P11,P12（6件） | P01,P02,P06,P07,**P09**,P11,P12（7件） |
| P09 status | alive（誤表示） | **eliminated**（正） |

既存経路の回帰なし：R3=P11/contract_violation、R5=P02/contract_violation、
R9=P06/bankruptcy、R11=P07・P01/bankruptcy はすべて再起動前後で一致。
R12は閲覧可能（`GAME_END` 到達済み）。

god view はtoken無しで403（認可境界維持、トークンは一切読み書き・出力していない）。

## 既知の未修正事項（別Plan扱い）

R12の `eliminated` に **P12が重複表示**（`SURVIVAL_CHECK` と `FORCED_LIQUIDATION` が
両方append）。前回devlog調査で修正前コードでも同一挙動と確認済みの**既存バグ**であり、
生存者数カウントには影響しない（`get_game_state()` 側で重複排除済み）。本作業のスコープ外として
未修正。

## 影響範囲

trial本体・`logs/`・engine state・engineプロセス・god.env・drop-in・Caddy設定は無変更。
Viewerは読み取り専用（GET専用）でログへの書き込みなし。公開閲覧者への影響は再起動時の
数秒間の瞬断のみ。
