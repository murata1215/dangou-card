# 2026-09-20 21:27 JST ｜ サイクル10.7: HttpAgentProvider（DevRelay 経由のサブスク席）の追加

DevRelayサーバーの `POST /api/agent/raw-completion` を叩くプロバイダーを新設し、Claude Fable / Opus をサブスク認証（API課金なし）で本戦に1席混ぜられるようにしたい、という依頼だった。既存のllm/adapters.pyはSDK直呼び前提の3アダプタしか無く、コスト計上・席キャップ・ログはmodel_id単価に強く依存している設計だったため、まず「単価0円のモデルを混ぜても既存の予算ガードや逆引きテストを壊さない道」を探した。

調査で分かったのは、アダプタが実は基底クラスの無いダックタイピングだったこと（`complete(system, messages, ...) -> (text, usage)` を持てば足りる）と、`llm/models.py`のレジストリテストが「単価は必ず正」「同一model_idは経済条件一致」「provider集合はVENDOR_ORDER」という3つの不変条件を機械的に守っていたこと。素直に単価0のエントリを足すと即座にこれらのガードに引っかかる設計だったので、`ModelInfo.billing`という新フィールドを足して"subscription"のときだけ`estimate_cost()`が0を返す、という一段回り道の実装にした。model_idは実在の`claude-opus-5`（H1）と衝突しないよう`devrelay/`接頭辞を必須にし、未指定は起動時ValueErrorにした。

seatKeyにプレイヤーIDを渡す経路が既存コードに存在しなかったため、`LLMAgent.__init__`にアダプタの`bind_seat()`をダックタイプで呼ぶだけの3行フックを足した。他のアダプタは`bind_seat`を持たないため無害。匿名化行（DevRelay経由だとOAuthメールアドレス等の実行環境情報が漏れうる）は`build_system_prompt()`側を一切変えず、`HttpAgentProvider.complete()`の送信直前にsystem末尾へ1行だけ足す形にして、既存プロンプトのログ・他プロバイダーへの影響をゼロにした。

リトライは429（targetBusy/rateLimited）と接続エラーだけに絞り、クライアント側read timeout（既にtimeoutS+30秒待った後）はリトライせず即座にAdapterErrorへ変換するようにした。単体テスト22件（httpx.MockTransportでリクエスト組み立て・429リトライ・stopReason=error・タイムアウト・0円計上・匿名化行・deniedTools警告・LLMAgent統合を検証）と、`tools/fake_devrelay.py`（契約どおりの固定JSONを返すstdlib HTTPServer）を使った結合テスト3件を追加し、`tests/test_registry_18.py`の単価スナップショットテスト2件（フィールド数固定・全価格正）だけ意図的に更新した。既存テスト全件（新規22件込みで1818件）がPASS。`tools/devrelay_smoke.py`は環境変数（DEVRELAY_URL/DEVRELAY_TOKEN）未設定だったため実行はスキップ扱いで正しく終了することのみ確認した。
