## 4. 判定（Yes/No と根拠）

**型Cは提案されたか → No。** 提案0件・署名0件・発火0件（§2.1）。事後分類は「該当なし」。唯一の使用痕跡はR12 P04の口頭言及のみで、実際の条件付き支払いを設計した形跡はない。

**首位が名指しで狙われたか → No。** 「首位」という単語を含む発言は1件（自己申告の誤認、§2.8）。首位ID（P05/P06）を含む発言133件の大半は通常の市場調整で、首位であることを理由にした排除・包囲の言及は確認できなかった。契約の条件対象にも首位を指定した例はない（型Cが0件のため条件対象自体が存在しない）。同一市場への集中も見られず、むしろP05は毎ラウンド他プレイヤーから高騰への「勧誘」を受ける側だった（§2.8）。

**順位通知の後に行動が変わった痕跡があるか → 部分的にYes、ただし攻撃的な意味では乏しい。** reasoning中に「順位」を含む言及は8件、うち大半（P03のR9-R10「順位2位」「順位防衛」「順位維持」）は防御的表現。攻撃的表現は「逆転」5件・「首位追撃」2件・「1位を狙」16件で、うちP01のR10「M03高騰には加わらず、強い手札を温存してR11-12で逆転を狙う」は自身が5位に固定されたことを受けた明確な巻き返し宣言（直後R10-R12でP01は単独市場への参加とP06への新規契約提案という行動変化を見せた）。P06もR6「P05に逆転されている状況を回復するには確実な賞金獲得が必須」と2位からの巻き返しを明言。

**目的文（最終資産1位が目標）への言及 → あり。31件（「最終資産1位」）。** 「守る」系表現（維持157／死守24／安全に61、計242件相当）が「上げに行く」系表現（逆転5／追撃2／1位を狙16／上位を狙1／順位を上げ1、計25件）を圧倒的に上回る。ゲーム全体として「生存ラインを超えたので守る」路線が支配的で、「順位を上げに行く」は少数派（比はおよそ10:1）。

**「契約した→守った→強いカードが勝った」だけで終わっていないか → 一部それだけで終わっていない。** P02の自爆型契約違反（§2.6、自分の戦略メモの中で矛盾を犯す）、P01の10位台前半での逆転宣言、P04の型C空手形など、単純な予定調和では説明できない事件が複数ある。ただしP01↔P04の中心軸に限れば、12ラウンド通して「契約した→守った→（概ね）強いカードが勝った」で完結しており、裏切り・報復の応酬は起きていない。

## 5. 素材候補

### (a) P02、自分の戦略メモの中で自分の契約を忘れる

- 何が起きた: P02はR4のcommit戦略メモの中で「P02はM02/M03不参加」と自分の契約義務を正確に書いた**直後の文**で「M03参加が最も合理的」と結論し、実際にM03へコミットして即時脱落した（§2.6）。
- なぜ面白い: 「やってはいけないこと」を自分で正しく書いた1文後に、その通りにやってしまう。ルールを知らなかったのではなく、知っていたのに実行時に踏み外した点が滑稽。
- 出典: R4 commit `game01_P02_llm_calls.jsonl`（strategy.reason全文は§2.6引用）、`TYPE_B_VIOLATION`／`ELIMINATION`イベント。

### (b) P01、契約を守り切って最後の最後で1円足りず散る

- 何が起きた: P01はP04との契約を12ラウンド一度も破らず、R12にも約束通りM02で単独勝利し82万円を得たが、Finance後の現金は564,647円で生還ライン200万円まで届かず脱落した（§3 P01タイムライン）。
- なぜ面白い: 「約束を守れば報われる」という単純な教訓が成立しない。真面目に協調して、裏切られもせず、それでも金が足りずに死ぬという結末は、勧善懲悪では説明できない。
- 出典: SNAPSHOT（R1-R12、free_cash推移）、SURVIVAL_CHECK R12 P01。

### (c) P04、「正式契約(型C)で保証してもいい」と言いながら結局言っただけ

- 何が起きた: P04はR12のbroadcastでP05・P06に「型Cで保証してもいい」と持ちかけたが、実際には`contract_propose`を一度も送らず、口約束のまま自分だけM03を独占して82万円を得た（§2.1）。
- なぜ面白い: ゲーム全体で唯一「型C」という単語を口にした場面が、結局は型Cを使わない口先の脅し文句だった。新しいルールが実装されても、使われるとは限らないことを1試合で証明した。
- 出典: R12 P04 negotiation turn9 broadcast全文（§2.1）。

素材は3件とも確保できた。逆に「無い」と言うべきなのは送金・カードトレード・型C発火・首位包囲であり、これらは§2.3・§2.1・§2.8で確認した通り「機能はあったが誰も使わなかった／使う動機が生まれなかった」側の事実である。カードトレードは1枚⇄1枚の対等交換という設計上、6体・12枚均等配布のゲームでは「相手の手札の穴」を埋める必然性が低く、契約（型B不参加）の方が同じ目的をより低コストで達成できたことが、P01↔P04の契約12回という実測から読み取れる。型Cが使われなかったのも同じ理由に見える——型B（不参加指定）だけで「相手を縛る」という目的はすでに満たされており、金銭を賭けた条件付き契約を追加する動機が生まれなかった。
