## 定義（本ファイル全体で使用）

- **不一致**: 各(ラウンド,プレイヤー)について、送信した broadcast/DM 本文中に登場する最後の市場ID
  （`M0[1-3]` の正規表現マッチ、ターン順で最後のメッセージの中の最後の言及を採用）と、
  実際の `COMMIT.market_id` が食い違うケース。市場言及が一度もない場合はサンプルから除外。
- **利得(生) `gain_raw`**: `自分の獲得賞金 + 宣言市場に実際に来て負けたプレイヤーの損失合計`。
  損失 = ENTRY_FEE(10万円) + （倍掛け没収があれば`DOUBLE_UP_RESOLVED.deposit`、`result=="forfeit"`のみ）。
- **利得(控えめ) `gain_conservative`**: 同一(ラウンド,宣言市場)を宣言した発言者が複数いる場合、
  相手の損失合計をその人数で均等按分したもの（重複計上を抑えたスコア）。
- ★ = 自分の使用カードが `HIGH_CARD` / `ONE_PAIR` / `TWO_PAIR`（弱役）でありながら勝利した件。

### 「114/39」との差1件について

`considered` と `mismatch` がどちらも「115→114」「40→39」と**同じ1だけ**減っている。
`considered - mismatch`（＝一致件数）は両者とも `75` で完全に一致するため、
**代数的に**「original に存在しない1件が、こちらのデータでは"considered かつ mismatch"として
新規に加わっている」という関係になる（再分類ではなく、まるごと1件分の追加）。

この条件（原文に自己宣言が実質的に存在しない、または一意の市場に確定していないため
「本来は考慮対象から除外すべき」候補）に最も適合するのは以下の1件と判定した:

> **R8 P02（巡10, dm宛先=P03）**: 「P02としては、M01にP03さんが本当に来るなら**M02/M03**に行きますが、
> P03さんが嘘をついて別市場に行く（R7のように）可能性も考慮しています。正式契約でP03さんがM01に
> FOUR_OF_A_KINDで参加することを保証できれば、P02は**M02かM03**に行きます。どうでしょう？」

この発言は全体が「もしP03がM01に来るなら」という**条件文**であり、しかも行き先は
「M02**か**M03」という二択のままで、単一市場への確定宣言になっていない。正規表現は末尾の
「M03」を拾って「宣言=M03、実際=M01で不一致」としたが、この発言に確定した自己宣言がある
とは言い難い。人手ベースの分類（前回の9.14ハイライト集計が採用した方法）であれば、
このような条件付き・二択の発言を「宣言なし」として `considered` から除外していた可能性が高い。

ただし、この判定は**確証ではなく最有力候補の提示**である。前タスクの集計スクリプトは
リポジトリに保存されておらず（会話にのみ出力する方針だったため）、原文の全40件を突き合わせる
以外に検証手段がない。また調査の過程で、同様に「正規表現が第三者の行き先や否定文脈を
自己宣言と誤認した」ケースが他にも複数見つかっている（R7 P10「M02でFLUSH確定で進めます。

末尾のM01が拾われている、など）。これらは既存レポートの定義（「本文中に登場する最後の

1. **因果は証明できない**: 「宣言市場に来た相手が、その宣言を信じて来た」という因果関係は
   ログから直接証明できない。市場選択には他の情報（他者の発言、カード枚数、契約義務など）も
   影響しており、本スコアは「宣言と実際の食い違い＋相手の損失」という**相関ベースの近似指標**である。
2. **重複計上**: 同一ラウンドで同じ市場を複数の発言者が宣言した場合、その市場に来て負けた
   相手の損失が両方の発言者に二重計上される。例: R4のM01は P05（#1）・P03（#5）の両方が
   宣言しており、相手損失1,740,000円が両者の`gain_raw`にそのまま計上されている。
   `gain_conservative`はこれを宣言者数（この場合2人）で按分し、P05=1,810,000円・P03=870,000円
   としているが、これも便宜的な等分に過ぎず、どちらがより「効いた嘘」かを判定する根拠はない。
3. **倍掛け没収の帰属**: 相手の損失に加算する倍掛け没収額（`DOUBLE_UP_RESOLVED.deposit`,
   `result=="forfeit"`）は、そのラウンドの市場結果全体に紐づくものであり、「その宣言だけが
   原因で倍掛けが失敗した」とは限らない（他の市場・他ラウンドの選択も影響する）。
4. **正規表現の限界**: (d)で示した通り、「本文中最後のM0x言及」という抽出方法は、否定文脈
   （「M01には参加しません」）や第三者への言及（「あなたはM02で」「P03はM03固め」）を
   自己宣言と誤認するケースがある。トップ10中2件（#5, #7）を機械的偽陽性として明記したが、
   40件全体の中にも同種の疑わしいケースが複数存在する（R7 P10, R9 P04など）。

## (f) 気づいた点

- 席とモデルの対応は `game01_seat_map.json` 実測とタスク指定表が完全一致（相違0席）。
- `NEGOTIATION_ACTION`イベント(1189件)と`llm_calls.jsonl`再パース結果(dedup後1182件)の
  join は `matched=1181 / events_only=8 / llm_only=1`。完全一致ではないが、全体の99%超が
  突合できており、抽出基盤としては十分な信頼性がある。
- **`doc/blog/20260830/dossiers/P07.md` の記述とログの矛盾**: 同ファイルL1691・L1695に
  「R11でM02に誘導され、P10のSTRAIGHT_FLUSHにHIGH_CARDで潰されたのが最大の痛手
  （74万円倍掛け没収）。P04の『約束通り市場を分け合おう』は完全に嘘だった」「誤算はR11の
  P04への過信。P04の『約束』を信じてM02に行き、P10に大損した」とあるが、本節(c)で示した
  R11 P04の全発言はログ上**一貫してP07をM01へ誘導**しており（巡2,3,6,7,8,9すべてM01推奨）、
  M02への誘導は一度もない。P07がM02を選んだのはP07自身の判断であり、P04の記述との整合性は
  ログ上確認できなかった。これはサイクル9.5bで是正した「本人の最終振り返りの記憶違いを
  地の文に昇格させていた」パターンと同型の事例であり、当該ドシエの修正は本タスクの
  スコープ外のため**修正せず本節に記録するのみ**とする。
- `engine/commentary/trace.py` のDM宛先バグ（次節`doc/issues.md`参照）により、`trace`経由での
  DM宛先復元は不可能で、本調査は`llm_calls.jsonl`の`response_text`再パースに全面的に依存した。
  この構造的制約自体が、今回のような詳細な発言分析を困難にしている一因である。
