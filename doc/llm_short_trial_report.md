## 1. カードトレード

**発生件数: 0件**

LLM が `card_trade_propose` を出力した回数: **0件**

RULES_SUMMARY にカードトレード提案の書式を記載し、response_parser にもパース処理を追加済みだが、6ラウンドの試行では**どのモデルもカードトレードを試みなかった**。

考察:
- 6R は短く、交渉ターン数も5巡と少ないため、カードトレード以外のアクション（DM、broadcast、pass）が優先された可能性
- LLM がカードトレードのルールを理解しつつも、手持ちカードの価値判断や交換相手の選定に至るまでの思考コストが高い
- 12R の本戦で再検証が必要

### 倍掛け選択理由（strategy.reason 原文）

**P01 (GPT-4.1 Mini) — 4回全て DOUBLE:**
1. R1: 「次ラウンド以降の賞金獲得に自信があり、資金効率を高めるために倍掛けを選択。失敗時の損失は許容範囲であり、リスクを取る価値があると判断。」
2. R3: 「現金153万円、借金82万円、Free Cash70万円と余裕があり、次ラウンドで市場獲得も狙えるため、リスクを取って賞金を倍にしたい。成功すれば資金増強と交渉力アップに繋がる。」
3. R4: 「現金に余裕があり、次ラウンドでの市場獲得に自信があるため、倍掛けで資産増を狙う。残りカードは強力で勝利の可能性が高い。」
4. R5: 「現金に余裕があり、次ラウンドでの市場獲得見込みもあるため、リスクを取って賞金を倍に増やす選択をします。残りラウンドが少なく、最終資産最大化のために積極的に動きたい。」

**P02 (DeepSeek V3 (L)) — 4回全て TAKE:**
1. R1: 「借金500万円に対して現金516万円と余裕はなく、26万円の没収リスクは大きい。」
2. R4: 「残りラウンドは3回。現金351万円、借金343万円でFree Cashは8万円しかなく...TAKEで確実に26万円を受け取り、返済とEntry Feeの余力を確保するのが安全。」
3. R5: 「...安全策としてTAKEを選び、確実に生還条件を満たすことを優先する。」
4. R6: 「残り1ラウンドで借金176万円、現金249万円。TAKEなら現金291万円で余裕の生還。DOUBLE失敗のリスクを負う価値がない。」

**P05 (DeepSeek V3) — TAKE 1回、DOUBLE 2回:**
1. R1 TAKE: 「Free Cashは16万円しかなく...ここは確実にTAKEで26万円を確保し、今後の交渉資金・返済原資を増やすのが安定策。」

3. R4 DOUBLE: 「...残りカードにはFOUR_OF_A_KINDやSTRAIGHT_FLUSHなどの強力なカードが残っており、市場獲得の見込みは十分にある。失敗リスクはあるが、現状のままでは生還が厳しいため、リスクを取る価値がある。」

### 注目すべき発見

1. **倍掛けは機能している**: GPT-4.1 Mini が4回連続 DOUBLE を選択し全て成功（合計 168万円の利益）。DeepSeek V3 (L) は4回全て TAKE を選択し安全策。戦略的判断が機能。
2. **カードトレードは未使用**: プロンプトに書式を記載済みだが、6R では発動しなかった。12R の本戦で再検証が必要。
3. **Kimi は安定化**: thinking 無効化により JSON 率 96%、レイテンシ 10s。Season 1 の 23%/99.5s から劇的改善。
4. **ソロ市場での倍掛け成功**: R4-R5 で from_solo_market=true の成功が3件。仕様§6.2 との整合確認が必要（engine 側の論点）。
5. **強制返済不能の実例**: Kimi が R1 倍掛け失敗 → R4 強制返済不能で脱落。S2 の新メカニクスが相互作用している。
